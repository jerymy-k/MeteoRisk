# MeteoRisk

Pipeline de données bout-en-bout pour anticiper les risques météorologiques liés aux livraisons dans les villes marocaines. Architecture Bronze/Silver/Gold automatisée avec Airflow, PostgreSQL et un dashboard Streamlit. Récupère les prévisions via Open-Meteo, calcule un Weather Risk Score (0-100) par ville/jour, et visualise les périodes à risque pour l'organisation des livraisons.
